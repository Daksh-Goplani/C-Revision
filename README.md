# C Revision

This repository documents my C programming practice while revisiting the language after learning it during my Polytechnic diploma. It contains small programs, examples, and exercises organized by topic so I can reinforce core concepts and track progress.

## Repository Structure

- `Array/` - array operations, matrix manipulation, searching, and sorting
- `Basic/` - simple arithmetic and control-flow examples
- `Functions/` - function usage, recursion, and modular code
- `Loops/` - loop patterns, series generation, and number exercises
- `OS/` - operating system experiments and demo code
- `Pointer/` - pointer basics, swapping, and dynamic memory allocation
- `Strings/` - string handling, palindrome checks, and character operations

## Learning Goals

- Strengthen understanding of C fundamentals
- Practice arrays, pointers, and memory management
- Improve problem-solving with concrete examples
- Learn cleaner, more organized C code structure
- Keep a revision-friendly codebase for B.Tech coursework
